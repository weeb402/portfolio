# Portfolio — MI6 Classified Dossier

Personal portfolio site for Vaibhav Goyal [007-DEV]: Next.js 15 (App Router), React 19, Tailwind CSS, TypeScript strict.

Live: https://portfolio-dusky-psi-70.vercel.app

## Systems

- Procedural gun-barrel intro with sessionStorage replay guard (`GunBarrelIntro`)
- Web Audio sound engine, zero audio assets (`src/utils/audioFX.ts`)
- 3D tilt cards with counter-directional specular glare (`Card3D`)
- IntersectionObserver scroll reveals + cipher-scramble titles (`Reveal`, `ScrambleText`)
- Seamless parallax tactical grid backdrop (`TacticalBackdrop`)
- Golden Gun easter egg: type `007` anywhere

## Commands

```bash
npm run dev     # local dev server
npm run lint    # ESLint (next/core-web-vitals)
npm run build   # production build + typecheck
```
